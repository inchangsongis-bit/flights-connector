Every flight search sorts by shortest, so a sixteen-hour layover in Tokyo ranks below every nonstop and vanishes. This one sorts the other way. Pick two cities and see which places in between are actually flyable on one ticket — and what a night there would cost you.

What's real here

Airports, timezones, the route graph and the stopover-programme table are real data. Flight times are not — no schedule feed is wired up yet, so the dial models a layover rather than reporting one.

Route graph

OpenFlights, roughly 2014. Deliberately used only as a candidate filter: it says a carrier once flew a pair, never that a seat exists today.

Booking

Links go to the carrier's own multi-city search — that is what makes it one ticket — plus a pre-filled per-leg check. No multi-city deep links: those formats are undocumented and break silently, which is worse than none at the booking step.

Real flights

The dial below models a layover. To see actual flights, run npm run find -- SEA ICN 2026-10-13 --json — the API key stays on your machine and only the results reach this page.

Entry rules

Evaluated against the layover date, not today — Korea's K-ETA waiver lapses 2026-12-31, so the same trip weeks later needs an authorisation. Advisory only: confirm with the government.

Stopover programmes

Hand-curated, . Terms shift by fare, cabin and point of sale. Every row is a lead to verify with the carrier, not a promise.
